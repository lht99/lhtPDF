lhtPDF Portable Mode

Keep this portable.txt file beside lhtPDF.exe to enable portable mode.

For a new portable installation, lhtPDF stores settings, log files,
crash-recovery autosaves and newly created digital IDs in:

    lhtPDFData

This folder is located beside lhtPDF.exe.

Compatibility with older portable versions:
- If lhtPDFData already exists, lhtPDF uses it.
- Otherwise, if PdfCraftData exists, lhtPDF uses that existing folder.
- If neither exists, lhtPDF creates lhtPDFData.

Existing PdfCraftData files are not automatically moved or deleted.

Copy the whole portable application folder, including its data folder,
to move lhtPDF together with its settings.

To disable portable mode, remove portable.txt while lhtPDF is closed.
Without a portable marker, the application uses its normal per-user
settings folders.

If the portable data folder cannot be written, lhtPDF reports the
problem and falls back to the normal per-user folders.
