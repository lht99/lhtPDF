lhtPDF portable mode

Keep portable.txt beside lhtPDF.exe to enable portable mode.

lhtPDF stores settings, logs, crash-recovery autosaves and
new digital IDs in the lhtPDFData folder beside the executable.

If PdfCraftData already exists and lhtPDFData does not exist,
lhtPDF reuses PdfCraftData to preserve existing portable data.

Copy the entire portable folder when moving lhtPDF.

Remove portable.txt to disable portable mode and use the normal
per-user storage locations.

If the portable data folder cannot be written, portable mode
is disabled and the application uses per-user storage instead.
